Extract the entire ZIP, then open index.html in a recent browser that supports
MP4/H.264 video. Keep the assets folder alongside index.html.
All videos, images, styles and scripts are included. No internet connection,
installation or external service is required.

Videos are muted. If autoplay is disabled by your browser, use the play controls.
Within each Scene-aware mesh animation row, the controls synchronize its videos.
The left and right panels of each paired example are part of one video.

The same files can be served by any static web server without a build step.
